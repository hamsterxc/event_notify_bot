Events notification bot This bot notifies about new, changed or cancelled events of various providers. A provider is a data source that provides a list of events that changes over time. An event is a piece of information that can include title, time, place and any other information the provider gives. Available providers: - babylon: Babylon Berlin movies. To give this bot a command, send /<command> <parameters>. Parameters are whitespace-separated. Available commands: - /help or /start (no parameters): this message; - /show <provider-name>: show provider's current events; - /status (no parameters): show current subscriptions; - /subscribe <provider-name>: subscribe to provider's updates; - /unsubscribe (no parameters) or <provider-name>: unsubscribe from provider's updates, provider name is optional if it's the only subscription.
